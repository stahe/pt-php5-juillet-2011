# Scripts PHP5 comentados

➡️ Curso relacionado: **[Introdução ao PHP5 através de exemplos](https://stahe.github.io/pt-php5-juillet-2011/)**

---

## Descrição geral

Este documento oferece uma **compilação de scripts em PHP5** que abrangem diversas áreas de aplicação da linguagem. Não se trata de um curso exaustivo, mas sim de uma **compilação de exemplos práticos** destinados a ilustrar certas características do PHP5 e a servir de base para a experimentação dos programadores.

Os scripts apresentados:
- estão comentados diretamente no código;
- são acompanhados pela **sua saída de consola**;
- por vezes são complementados com **explicações adicionais** para ajudar a compreender melhor como funcionam.

O objetivo deste documento é oferecer uma **abordagem prática da linguagem PHP5**, baseada no estudo e na análise de scripts.

---

## Público-alvo

Este documento destina-se a programadores que **já tenham utilizado uma linguagem de scripting**, como:

- Perl;
- Python;
- VBScript;

Por conseguinte, pressupõe-se que o leitor tenha **alguma familiaridade com os conceitos de scripting**.

Os leitores que não possuam essa experiência prévia devem começar por um **curso completo sobre PHP** antes de utilizar esta compilação de exemplos.

---

## Método de leitura

Este documento requer uma **leitura ativa**:

1. Leia o código do script.
2. Examine os comentários incorporados.
3. Estude os resultados de execução fornecidos.

É a combinação destes três elementos que lhe permite compreender plenamente cada exemplo.
